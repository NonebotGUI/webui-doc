# 安装适配器

Base URL： `ws://ip:port`

| 类型    | 说明                           | 备注                                    |
| ----- | ---------------------------- | ------------------------------------- |
| 方法    | WebSocket                     |                                       |
| 入口 | `adapter/install` | 需要携带 `?data={json}` 参数 |
| 调用方式  | 异步调用                     |                                       |
| 请求格式  | 字符串 (String)              | `adapter/install?data={json}&token=your_token` |
| 返回类型  | JSON                         |                                       |

## 请求参数
`data` 应为 JSON 字符串，包含以下字段：
- `name` (String): 适配器名称
- `id` (String): Bot 的 uuid

## 返回示例
```json
{
  "type": "installAdapter",
  "data": {
    "status": "Adapter {name} start installing..."
  }
}
```
